Theme Name: Mashud Telecom
Author: magraphice
Version: 1.0.0
Description: Installable modern digital banking WordPress Theme code package with core system controller.

Instructions:
1. Upload this zip file through WordPress Appearance -> Themes -> Add New -> Upload.
2. Activate the theme.
3. In the WordPress Administration Menu, click on the "Mashud Telecom" menu.
4. Click "Auto-Create All Missing Pages & Assign Templates" to programmatically build the Register, Login, and Dashboards.
5. Click "Initialize / Repair Schema" to verify MySQL database tables exist.
